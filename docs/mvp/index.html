Diseño inicial

¿Por qué cuatro nodos temporales?

Esta primera versión prioriza una diadema ligera y repetible. Las cuatro posiciones temporales se seleccionaron porque conservaron cobertura retrospectiva útil en las pruebas de investigación y reducen los contactos, el ruido práctico y la complejidad frente a un montaje clínico extenso. No sustituyen un EEG clínico multicanal ni se presentan como una superioridad universal: una configuración de seis nodos puede evaluarse después para un paciente o protocolo específico.

Guía rápida

Cómo usar esta demostración

  1. Elige uno de los dos ejemplos públicos. Cada uno representa una sesión independiente.
  2. Identifica los primeros ocho minutos: son la calibración individual y no deben interpretarse como un estado de riesgo.
  3. Revisa la transición de colores. Verde es compatibilidad con la referencia; amarillo y naranja muestran cambio temprano o sostenido; rojo registra una trayectoria consolidada para investigación.
  4. Activa o desactiva la anotación retrospectiva para comparar visualmente el resultado del pipeline con el inicio anotado del conjunto de datos. La anotación no intervino en el cálculo.
  5. Descarga JSON o CSV para inspeccionar las ventanas derivadas y reproducir la visualización.
